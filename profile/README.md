<p>住宅 IP 掉线不全是服务商的问题，家庭宽带的波动、代理层的配置、客户端的回收，都可能表现为断线。本文按层拆原因，给一张现象对照表，再讲长期运行的保活设置和选型时该看的参数。</p>
<h2>一、掉线要分四层看</h2>
<p>第一层是上游线路，光猫、拨号、运营商侧，断了就是整条不通。</p>
<p>第二层是住宅资源本身，房东重启路由器、运营商维护，都会让地址短暂消失。</p>
<p>第三层是代理服务，端口、鉴权、会话数限制；第四层是客户端和本地网络。</p>
<h2>二、家庭宽带的天然波动</h2>
<p>住宅线路是共享资源，晚高峰拥塞、临时断电、设备重启都很常见。</p>
<p>这类波动通常持续几分钟到几十分钟，重连就能恢复，不算故障但要计入可用率。</p>
<p>如果每天固定时段断，多半是上游的维护窗口，可以要求服务商换一条线路。</p>
<h2>三、代理层与客户端的坑</h2>
<p>会话数超限是最常见的原因，多台设备同时跑满连接，新连接直接被拒。</p>
<p>客户端把长连接当空闲回收，表现为每隔一段时间断一次，需要开保活。</p>
<p>本地防火墙或安全软件拦截非常规端口，也会造成时通时断，换端口就能验证。</p>

<h2>四、按现象定位的顺序</h2>
<p>先在同一台设备上 ping 网关和出口地址，判断是本地断了还是出口断了。</p>
<p>再看代理端口能不能连上，能连上是应用层问题，连不上是链路或鉴权问题。</p>
<p>最后换设备、换网络各试一次，两次结果一致，基本可以排除本地因素。</p>
<h2>五、长期运行的保活设置</h2>
<p>TCP 保活开在六十到一百二十秒之间，太短会产生大量无效包，太长会被中间设备先回收。</p>
<p>应用层心跳三十到六十秒一次，配合指数退避重连，避免断线瞬间的请求风暴。</p>
<p>并发连接数留出两成余量，跑满套餐上限时，新请求会被拒或者被限速。</p>

<h3>自动切换值不值得做</h3>
<p>有备用地址时，做健康检查和自动切换，能把断线影响压到几十秒内。</p>
<p>只有一条线路就没必要，切换无处可去，不如把重连和告警做好。</p>
<h2>六、选型时能降掉线率的参数</h2>
<p>看是否独享，共享地址被别人跑满带宽时，你这边表现就是慢和断。</p>
<p>看线路冗余，双 ISP 的上游有备份，单条线路出问题时影响面小一些。</p>
<p>看服务商的更换政策，掉线频繁时能不能免费换地址，比承诺多少可用率更实际。</p>
<h3>可用率数字怎么理解</h3>
<p>宣传里的可用率通常是月度统计，短时间多次中断也可能达标，别只看那个百分比。</p>
<p>更该问的是单次故障的平均恢复时长，这个数字才对应你的实际感受。</p>
<h2>常见问答</h2>
<h3>住宅 IP 每天掉一次正常吗？</h3>
<p>答：不正常，重启后能恢复说明链路可用，但每天固定中断通常指向上游维护或会话限制，应该要求更换。</p>
<h3>掉线会导致账号异常吗？</h3>
<p>答：频繁的地址变化会让登录记录看起来不连续，是否影响取决于平台策略，稳定出口总是更稳妥。</p>
<h3>自己重启光猫有用吗？</h3>
<p>答：对本地拨号异常有效，对上游资源问题无效，重启两次仍不通就直接联系服务商。</p>
<h3>双 ISP 是不是就不会断？</h3>
<p>答：上游有备份，抗故障能力更强，但客户端、本地网络和服务商侧的问题依然存在，不存在完全不中断的线路。</p>
